# RhinoViterRuntimeScripts

Reloadable runtime F# commands.

The installed `.rhp` is a small permanent host. Command implementations live in a separate payload DLL.

## Install

```powershell
.\build-and-install.ps1
```

## Template

Based roughly off of [Github F# Template - RhinoFSharpTemplate](https://github.com/Viterkim/RhinoFSharpTemplate)
